# Plan Do See Diary — ALEPH T06

## 로컬 준비
1. Node.js LTS 설치
2. `npm install`
3. MariaDB에서 `db/schema.sql` 실행
4. `.env.example`을 참고해 환경변수 설정
5. Vercel CLI 또는 Vercel 프로젝트에서 실행/배포

## 주의
`.env`와 DB 비밀번호는 Git에 올리지 않습니다. T06에는 로그인/인증을 추가하지 않습니다.

## 과제 데이터
배포 후 본인의 실제 계획 1개 이상, 할 일 5개 이상, 실행 기록 3개 이상을 입력합니다.
